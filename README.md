# 掌纹算命 🔮

一个基于 Web 的掌纹算命应用，通过分析掌纹三大主线（生命线、智慧线、感情线）为用户提供趣味性的运势解读。

## 功能特性

- 🖐️ 三大主线解读：生命线、智慧线、感情线
- 🎴 综合运势分析：事业、爱情、健康、财运
- 📱 响应式设计，支持移动端访问
- 🎨 精美的中式玄学风格界面

## 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- 无需后端，纯前端实现
- 响应式布局

## 快速开始

直接在浏览器中打开 `index.html` 即可使用，或使用本地服务器：

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8000

# 然后访问 http://localhost:8000
```
